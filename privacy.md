# Politique de Confidentialité

Cette politique de confidentialité explique comment notre Bot Discord collecte, utilise et protège vos données. En ajoutant ou en utilisant ce bot, vous acceptez les pratiques décrites ci-dessous.

## 1. Données collectées
Le bot traite uniquement les données strictement nécessaires à son fonctionnement fourni par l'API de Discord :
* Les identifiants Discord (User ID, Server ID, Channel ID).
* Les pseudonymes et avatars.
* Les messages textuels uniquement lorsqu'ils commencent par le préfixe du bot ou l'utilisation d'une commande Slash.

## 2. Utilisation des données
Les données collectées sont utilisées exclusivement pour :
* Exécuter les commandes demandées par les utilisateurs.
* Assurer le bon fonctionnement des fonctionnalités du bot sur votre serveur.

## 3. Partage et stockage des données
* Nous ne vendons, ne partageons et ne transférons aucune donnée utilisateur à des tiers.
* Les données temporaires ne sont pas conservées. Les données nécessaires à la configuration (ex: salons de logs) sont stockées de manière sécurisée.

## 4. Suppression des données
Si vous souhaitez que vos données associées à ce bot soient supprimées de nos systèmes, ou si vous souhaitez retirer le bot de votre serveur, vous pouvez contacter le propriétaire du bot directement sur Discord.
